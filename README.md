# الرفع إلى GitHub — لتشغيل التحديث 24/7 بدون جهازك

هذه الحزمة تجعل GitHub يجمع الأخبار كل ساعة (مجانًا) ويكتبها في Supabase الخاصة بك،
بلا أي تدخل منك بعد إعدادها لمرة واحدة.

## الملفات الموجودة في هذه الحزمة
- `.github/workflows/update.yml` — جدول التشغيل (كل ساعة + زر تشغيل يدوي)
- `sources.py` + `aggregate.py` + `fulltext.py` + `prune.py` + `db.py` — محرك الأخبار

---

## خطوات الإعداد (مرة واحدة فقط)

### 1) أنشئ حساب GitHub (إن لم يكن لديك)
- اذهب إلى https://github.com/signup واتبع الخطوات.

### 2) أنشئ مستودعًا جديدًا وارفع الملفات
- من داخل حسابك اضغط **New repository** (زر أخضر).
- الاسم: `middle-east-now` (أي اسم تريده)
- اختر **Public** (المجاني) ثم **Create repository**.
- افتح المستودع ثم اضغط **Add file ← Create new file** وارد أنشئ هذه الملفات
  مكانًا تلو الآخر (الصق المحتوى من مجلد `github_deploy`):
  1. اكتب في خانة اسم الملف: `.github/workflows/update.yml` والصق محتوى الملف
  2. اكتب `sources.py` والصق محتواه
  3. اكتب `aggregate.py` والصق محتواه
  4. اكتب `fulltext.py` والصق محتواه
  5. اكتب `prune.py` والصق محتواه
  6. اكتب `db.py` والصق محتواه
- بعد كل ملف اضغط **Commit changes** (استمر بالكتابة فوق أي نص).

### 3) أضف مفتاحي الوصول كأسرار (Secrets)
- من داخل المستودع: **Settings** ← **Secrets and variables** ← **Actions**
- زر **New repository secret** مرتين:
  - الاسم: `SUPABASE_URL`  → القيمة: `https://spemfwzbgdqpuctjgkkv.supabase.co`
  - الاسم: `SUPABASE_KEY`  → القيمة: مفتاح supabase الحالي (sb_publishable_...)

### 4) جرّب التشغيل أول مرة
- افتح تبويب **Actions** ← ستجد العمل `MEN-Update`
- اضغط **Run workflow** ← زر أخضر ← يبدأ فورًا.
- بانتظار الدائرة الخضراء (دون 10 دقائق غالبًا).
- ثم ادخل على صفحة الأخبار في جهازك واضغط **تحديث الآن** — ستجد أخبار اليوم.

---

## بعد ذلك
- يعمل كل ساعة تلقائيًا (من 00 إلى 59:00 كل ساعة بتوقيت GitHub العالمي،
  أي بفرق ~ساعة عن توقيتك المحلي — التفاصيل أدناه).
- زر **Run workflow** في تبويب Actions يسمح لك بالتشغيل اليدوي أنى شئت
  (حتى من هاتفك).
- أي تحديث في الملفات داخل المستودع يُعدّل العمل مستقبلًا إذا أعدت الرفع.

## ملاحظات
- الاستضافة مجانية تمامًا (عمر GitHub البطاقة: 2000 دقيقة شهرية تكفي أيامًا عدة يوميًا).
- وقت التحديث عالمي (UTC): الساعة التي تظهر في الموقع = ساعة جهازك - 2~3 بحسب منطقتك.
  إن أردت التحديث عند ساعتك من الصباح بالضبط كل يوم، بغير الخيار مضبوطًا على ساعة GitHub.
- لا ترفع أبدًا `data/supabase_config.json` ولا أي ملف به مفاتيح إلى المستودع.
